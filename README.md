**✍️ Text to Handwritten Text Converter**

A simple Python GUI application that converts normal typed text into handwritten-style text using **Tkinter** and **Pillow**.

**🚀 Features**

- Convert typed text into handwritten-style text
- Simple and user-friendly GUI
- Supports multiple lines
- Handwriting font support
- Preview generated output
- Save output as an image

**🛠️ Technologies Used**

- Python
- Tkinter
- Pillow (PIL)

## ⚙️ Installation

Install the required library:

```bash
pip install Pillow
```

## ▶️ How to Run

```bash
python handwriting.py
```

## 📝 How It Works

1. Enter text in the application.
2. Select the handwriting style.
3. Click **Generate**.
4. Preview the handwritten text.
5. Save the generated image.
