# ✍️ Text to Handwriting Generator

A Python-based **Text to Handwriting Generator** that converts typed text into a handwritten-style notebook page.

The application provides a simple **Tkinter GUI** where users can enter or paste text and convert it into a handwritten-style PNG image using Python's Pillow library and a handwriting-style Windows font.

---

## 📌 Features

- ✍️ Convert typed text into handwriting-style text
- 🖥️ Simple and user-friendly Tkinter GUI
- 📄 Generates an A4-style notebook page
- 📏 Blue ruled notebook lines
- 🔴 Red left-side margin
- 🖊️ Blue ink-style text
- 🔤 Uses Windows built-in fonts
- ❌ No `handwriting.ttf` file required
- 💾 Automatically saves the generated image
- 👀 Displays a preview of the generated handwriting
- 🧹 Clear button to remove entered text
- 📂 Supports Windows and Python 3.x

---

## 🛠️ Technologies Used

- **Python**
- **Tkinter** – GUI development
- **Pillow (PIL)** – Image generation and text rendering
- **Windows Fonts** – Handwriting-style font
